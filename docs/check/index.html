Check a box

Type three edges, of any size, and see all seven lengths: which are whole, and how close the box comes to a perfect cuboid. Everything is worked out in your browser.

Drag the box to turn it. Whole lengths in blue, irrational ones dashed in red.

Search in your browser

The same search as the command line's, on every smallest edge up to a limit, run in a background thread of your browser. It lists the primitive Euler bricks as it finds them.

    Scala 3 compiled to JavaScript with Scala.js, from perfectcuboid.
